# Demonstration records

Demo records are generated by executing the instrumented LangGraph workflow,
not by inserting invented trace durations. A clean startup executes seven
scenarios. Use `python -m scripts.benchmark` to execute a paired four-case
benchmark and export `benchmark-report.json`. That generated report contains
local trace IDs; it is evidence from that database, not a portable fixture.

Mock responses and regex token units are simulated. Their prices are illustrative
configuration. All demo records have `source=demo`, `mode=mock`. Provider runs
have `source=collected`, `mode=provider`. Analytics never combine these scopes.
